FAQ
Q: I bought Gemini Enterprise.  Do I have Code Assist?

Yes. Gemini Enterprise is a "soft bundle." It includes a subscription to Gemini Code Assist Standard.
Action Required: You must still assign these licenses in the Google Cloud Console. 

Q: Where do I manage these licenses? All GCA licensing is handled at the Google Cloud Billing Account level via the Admin for Gemini page.

Q: How do I see who is actually using the tool? In the Admin for Gemini dashboard, you can see the "Last Active" date for every assigned user. This is the best way to track engagement during a PoC.

Q: Can I see productivity metrics? Yes. You can use Cloud Monitoring to track GCA usage metrics like Acceptance Rate (the percentage of AI suggestions your developers actually kept).

Dashboard Link: Cloud Monitoring for Gemini (Search for Gemini Code Assist).

Q: Will our code be used to train Google's models?

No. For Gemini Enterprise and Code Assist customers, your code, prompts, and generated recommendations are never used to train foundation models.
Data Governance: See the Official Gemini Data Governance page for full details to share with your Security/Legal teams.

Q: Troubleshooting Common PoC Issues
"Unauthorized" error in IDE: Ensure the user has the Service Usage Consumer role on the project.
"No Licenses Available": Check your License Pool. If you are using Automatic Assignment, reduce the "Inactivity Period" to reclaim seats faster.
Trial Limitations: If you are on a self-serve free trial, you are limited to 50 licenses for 30 days. If you need to expand, you must convert to a paid subscription or contact your sales rep for an exception.

Proxy Configuration & Domain Whitelisting

To use Gemini CLI and the Gemini Code Assist IDE extensions behind a corporate proxy, your network team must whitelist the following domains for HTTPS (Port 443) traffic.

Core Service Domains
The primary endpoints for AI generation and authentication.
- generativelanguage.googleapis.com (Core Gemini API)
- cloudaicompanion.googleapis.com (Gemini Code Assist Service)
- oauth2.googleapis.com (Authentication & Token Refresh)

Project & Resource Management
Used for validating licenses and managing GCP project resources.
- serviceusage.googleapis.com
- cloudresourcemanager.googleapis.com
- apihub.googleapis.com
- stitch.googleapis.com

IDE & CLI Specific Endpoints
Required for extension features and tool updates.
- cloudcode-pa.googleapis.com (IDE-specific features)
- registry.npmjs.org (Required for Gemini CLI updates)

Telemetry, Feedback & Assets
Used for service monitoring and UI assets.
- firebaselogging-pa.googleapis.com (Telemetry)
- feedback-pa.googleapis.com (User feedback)
- play.googleapis.com (Telemetry initialization)
- lh3.googleusercontent.com / lh5.googleusercontent.com (User profile photos)

Configuration Instructions
Set the following environment variables in your terminal or system settings:
export HTTP_PROXY="http://your.proxy.address:port"
export HTTPS_PROXY="http://your.proxy.address:port"

Note: If your proxy uses a custom CA certificate, ensure it is added to your local system trust store or the Node.js/Python environment.

Gemini 3 Pro & Flash Configuration

DBS can now leverage the latest Gemini 3 models within the CLI and IDE extensions.

Requirements:
1. Administrative Enablement: Ensure the "Preview" release channel is enabled in the Google Cloud Console for the relevant project.
2. CLI Version: Ensure you are using @google/gemini-cli v0.21.1 or higher.
3. Settings: Use the /settings command in the CLI to opt into the preview channel.

Model Identifiers for CLI:
- gemini-3-pro-preview
- gemini-3-flash-preview

Adoption Journey & Best Practices

To ensure a smooth rollout across DBS development teams, we recommend the following:

1. Visual Feedback Loop: Use the Zed IDE integration with Gemini CLI to allow senior developers to review code diffs in a high-speed, graphical environment.
2. Feedback Mechanism: Instruct developers to use the built-in feedback widget in IDE extensions for bugs. This provides the most context for resolution.
3. Language Focus: While 20+ languages are supported, ensure teams using Go, Java, JavaScript, and Python are prioritized as these have the highest optimization levels.
4. Privacy Assurance: Remind developers that for Gemini Enterprise customers, code and prompts are NOT used for training foundation models.
5. Metrics: Use the Cloud Monitoring dashboard to track "Acceptance Rate" as a primary KPI for adoption success.
