FAQ
Q: I bought Gemini Enterprise.  Do I have Code Assist?

Yes. Gemini Enterprise is a "soft bundle." It includes a subscription to Gemini Code Assist Standard.
Action Required: You must still assign these licenses in the Google Cloud Console. 

Q: Where do I manage these licenses? All GCA licensing is handled at the Google Cloud Billing Account level via the Admin for Gemini page.

Q: How do I see who is actually using the tool? In the Admin for Gemini dashboard, you can see the "Last Active" date for every assigned user. This is the best way to track engagement during a PoC.

Q: Can I see productivity metrics? Yes. You can use Cloud Monitoring to track GCA usage metrics like Acceptance Rate (the percentage of AI suggestions your developers actually kept).

Dashboard Link: Cloud Monitoring for Gemini (Search for Gemini Code Assist).

Q: Will our code be used to train Google's models?

No. For Gemini Enterprise and Code Assist customers, your code, prompts, and generated recommendations are never used to train foundation models.
Data Governance: See the Official Gemini Data Governance page for full details to share with your Security/Legal teams.

Q: Troubleshooting Common PoC Issues
"Unauthorized" error in IDE: Ensure the user has the Service Usage Consumer role on the project.
"No Licenses Available": Check your License Pool. If you are using Automatic Assignment, reduce the "Inactivity Period" to reclaim seats faster.
Trial Limitations: If you are on a self-serve free trial, you are limited to 50 licenses for 30 days. If you need to expand, you must convert to a paid subscription or contact your sales rep for an exception.
